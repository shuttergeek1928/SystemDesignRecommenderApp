Advantages:
* Allows user to map users to organizations and teams in Grafana Enterprise.
* Set permissions on folders and dashboards
* Enhanced data visualization with rich annotations
* ability to share across teams within an organization or contribute to a community-wide resource.
* ease of use in creating single and multiple dashboards through scripts
* Grafana Mimir provides scalable long-term storage specifically designed for Prometheus.
* Ability to configure default ports according to organizational standards
* flexibility in using the same dashboard for different environments like production and test servers
* Flexible and vendor-neutral distribution of OpenTelemetry Collector
* Ability to send alerts through various channels such as PagerDuty, SMS, email, VictorOps, OpsGenie or Slack
* Turns TSDB data into insightful graphs and visualizations
* Flexibility in creating custom notifiers with code using Alert hooks
* Access to hundreds of dashboards and plugins
* Split view and comparison of different time ranges, queries, and data sources side by side.
* Grafana Pyroscope allows understanding workload’s resources usage down to the line number through continuous profiling.
* Continuous addition of new ones by community members every week
* Ability to create separate user groups
* Improved troubleshooting and issue resolution by correlating disparate datasets
* Compatibility with popular open source observability standards
* Connect other data sources like NoSQL/SQL databases, ticketing tools or CI/CD tooling
